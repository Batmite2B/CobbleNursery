# CobbleNursery

CobbleNursery adds Pokémon breeding and egg incubation to Cobblemon. Pair compatible Pokémon at the nursery terminal, collect their eggs, and hatch them in incubation nests.

Made for Minecraft 1.21.1 on Fabric with Cobblemon 1.8.x.

## Contribute

Bug fixes and addon ideas are welcome. Open an issue to report a bug or discuss an addon, or send a pull request with a fix. For bugs, include your Minecraft, Cobblemon, and CobbleNursery versions and what you did before the issue appeared.
